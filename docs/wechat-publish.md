# 微信小程序注册与上架清单

> 当前项目可先本地完整跑通。上架前需你在微信公众平台完成账号注册与主体认证。

## 一、注册小程序

1. 打开 [微信公众平台](https://mp.weixin.qq.com/)
2. 注册 → 选择「小程序」
3. 选择主体：
   - **个人**：可体验开发，部分类目/能力受限
   - **企业**：正式运营、更多类目，通常需要营业执照
4. 完成管理员绑定与邮箱激活
5. 获取 **AppID**（开发 → 开发管理 → 开发设置）

## 二、类目建议

按「本地生活信息 / 生活服务 / 信息查询」等实际开放类目选择（以微信后台最新类目为准）。

定位话术建议与产品一致：

> 乡镇本地物品租赁信息平台，提供商品信息展示与联系商家，不提供在线交易支付（MVP）。

避免在未实现支付能力时勾选电商交易类目。

## 三、代码侧配置

1. `miniprogram/project.config.json` 将 `appid` 改为真实 AppID  
2. 根目录 `.env` 填写：
   - `WECHAT_APPID`
   - `WECHAT_SECRET`
3. 关闭或限制 `APP_ENV=local` 下的 `/auth/dev/login`（生产必须 `APP_ENV=prod`）
4. `miniprogram/utils/config.js` 的 `baseURL` 改为 `https://api.你的域名.com/api/v1`

## 四、服务器与域名

提审/正式版要求：

- 备案域名 + **HTTPS**
- 微信公众平台配置：
  - request 合法域名
  - uploadFile 合法域名
  - downloadFile 合法域名

不要使用：`localhost`、内网 IP、HTTP。

部署提纲见 `docs/deploy.md`。

## 五、隐私与合规（审核高频）

1. 小程序后台填写「用户隐私保护指引」  
2. 小程序内提供：
   - 用户协议页：`pages/legal/agreement`
   - 隐私政策页：`pages/legal/privacy`  
3. 若使用位置能力：说明用途，并允许拒绝后手动选地区（本项目已支持）  
4. 商家/商品必须审核后公开展示（本项目已实现）  
5. 微信号默认不暴露，登录后点击再展示（本项目已实现）

请将协议文案替换为法务审定版本后再提审。

## 六、提审前自检

- [ ] 生产 API HTTPS 可访问  
- [ ] 合法域名已配置  
- [ ] AppID / Secret 已配置，真机微信登录可用  
- [ ] 首页有可浏览内容（或空态友好）  
- [ ] 联系商家可用  
- [ ] 隐私政策 / 用户协议可打开  
- [ ] 无「支付/订单」等未实现能力的误导文案  
- [ ] 测试号内容已清理，使用正式类目说明  

## 八、相册/相机与隐私指引

开发调试阶段小程序 `app.json` 中 `__usePrivacyCheck__` 为 `false`，否则未在公众平台配置隐私指引时，真机调用相册/相机会被拦截。

正式提审前：

1. 公众平台 → 设置 → 服务内容声明 → **用户隐私保护指引**  
2. 声明「收集用户选中的照片或视频信息」「摄像头」等，用途写「商家上传商品图片」  
3. 将 `__usePrivacyCheck__` 改回 `true`  
4. 使用官方同意按钮完成授权后再调 `chooseMedia` / `chooseImage`
